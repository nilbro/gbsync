# gbsync

Sync metrics and fact tables to GrowthBook.

## Installation

```bash
pip install gbsync
```

## Quick Start

```bash
export GB_API_KEY="your_api_key"
export GB_API_URL="https://api.example.com"

gbsync plan
gbsync apply
```
